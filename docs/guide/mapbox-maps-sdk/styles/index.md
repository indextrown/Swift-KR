# Swift로 이해하는 Mapbox 지도 스타일

> **면접 답변 한 줄 요약:** 지도 Style은 데이터 공급원과 그리기 규칙을 묶어 지도 모습을 정하며, 앱은 기본 지도를 선택하고 필요한 데이터와 표현을 별도로 추가해요.

공식 [Map Styles](https://docs.mapbox.com/ios/maps/guides/styles/)에 대응하는 학습 길잡이예요. 기본 지도를 고르는 일과 매장 데이터를 표시하는 일을 분리해서 읽어봐요.

## 먼저 알아둘 용어

| 용어            | 쉬운 뜻                                              |
| --------------- | ---------------------------------------------------- |
| Style           | 지도 데이터와 시각적 표현 규칙을 묶은 설계도예요.    |
| Basemap         | 도로·지명처럼 앱 데이터의 배경이 되는 기본 지도예요. |
| Mapbox Standard | SDK가 기본으로 사용하는 지도 스타일이에요.           |
| Runtime         | 앱이 실행 중인 시점을 말해요.                        |

## 네 가지 질문으로 나눠요

공식 [Map Styles](https://docs.mapbox.com/ios/maps/guides/styles/)는 기본 스타일 선택, 실행 중 데이터·Layer 변경, Expression, 선언적 구성을 연결해 설명해요.

| 변경 명령보다 현재 상태를 선언하려면요?  | [선언적 지도 스타일링](./declarative-map-styling.md) |

Mapbox Studio는 스타일을 만드는 도구이고, 이 문서 묶음은 앱에서 스타일을 사용하는 과정에 초점을 맞춰요.

## 매장 지도 변경 요청을 분류해요

다음은 기능을 구현하기 전에 해볼 수 있는 설계 연습이에요.

1. “야간에 눈부심을 줄여 주세요”는 기본 지도 설정부터 검토해요.
2. “신규 매장을 표시해 주세요”는 데이터 변경이에요.
3. “예약 가능한 매장을 파란색으로 보여 주세요”는 데이터와 표현 규칙을 연결하는 문제예요.
4. “필터를 끄면 일부 표시가 남아요”는 상태와 표시 수명 문제일 수 있어요.

모든 요구를 스타일 전체 재로딩으로 해결하면 원인 파악이 어려워져요. 무엇이 달라졌는지 먼저 이름 붙여 보는 것이 목적이에요.

## 면접에서 이어질 수 있는 질문

### 스타일은 단순한 색상 테마인가요?

아니요. 데이터 공급원과 Layer 구성도 포함해요. 색상은 그 구성의 일부예요.

### Studio에서 편집하면 앱 코드가 필요 없나요?

화면 요구에 따라 달라요. 로그인한 사용자의 즐겨찾기처럼 실행 중 바뀌는 데이터는 여전히 앱에서 연결해야 할 수 있어요.

### 먼저 Expression부터 외워야 하나요?

아니요. 작은 데이터와 고정된 Layer로 시작해요. 같은 데이터에 반복되는 표시 규칙이 생길 때 Expression을 도입하면 목적이 분명해져요.
